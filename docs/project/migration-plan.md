# 개발 진행 계획

## 완료

- `client`, `server`, `shared`를 루트 npm workspace로 등록했다.
- NestJS 서버의 기본 응답을 `GET /health`와 공유 타입 계약으로 교체했다.
- 템플릿 전용 관측·배포 의존성을 제거했다.
- `client`를 Vite에서 Next.js App Router 기반으로 전환하고, 루트 Turborepo 명령으로 전체 workspace의 개발·빌드·품질 검사를 통합했다.

## 다음 작업

1. 키워드 기반 랜덤 채팅과 회원·비회원 로그인 화면을 Next.js 기반으로 구현한다.
2. NestJS 서버에 회원 로그인과 비회원 로그인, 사용자 정보, 데이터 접근 구조를 정리한다.
3. 데이터베이스 정규화와 기존 데이터 이전 계획을 검증한다.
4. 키워드 기반 랜덤 매칭 대기열과 Socket.IO 채팅 계약을 설계하고 단일 서버에서 검증한다.
5. React Native WebView 기반 Android 앱이 웹 사용자 화면을 재사용하도록 준비한다.
6. MVP 범위의 QA와 재배포를 진행한다. 결제, 메가폰, 신고, 관리자, 알림은 후속 단계에서 다룬다.
